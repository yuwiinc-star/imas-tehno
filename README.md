# Сайт ИМАС-Техно

Прототип нового сайта imas-tehno.ru. Один файл `index.html` со всеми встроенными ресурсами.

- `src/site-template.html` — исходник сайта (CSS, разметка, скрипты)
- `src/assets/` — рендеры, модели GLB, видео первого экрана
- `src/build.py` — сборка: `python3 src/build.py` → `index.html`
- `материалы/` — фото, видео, изображения из презентаций (оригиналы не в репозитории)
- `модели/`, `логотип/` — 3D-модели и варианты логотипа
- `схема-сайта.html`, `карта-продукции.html`, `запрос-заказчику.html` — рабочие документы
