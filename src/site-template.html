Порционные машины с подсушкой

Можно наносить до четырёх разных компонентов отдельно друг от друга, с подсушиванием между нанесениями.

Есть возможность вносить сухой компонент: сухой инокулянт, тальк для подсушки, красители, смесь для дражирования.

Зерно бывает разным. Оператор меняет параметры работы «на лету» и качественно обрабатывает любые партии, независимо от их исходных характеристик.
